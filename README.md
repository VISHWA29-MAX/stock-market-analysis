# 📊 Stock Market Data Analysis

## 📌 Project Overview

This project focuses on performing **Exploratory Data Analysis (EDA)** on a Stock Market dataset using Python.

The dataset is analyzed to understand its structure, explore different categories, perform numerical operations, and visualize important patterns in the data.

---

## 🛠️ Technologies Used

- 🐍 Python
- 🐼 Pandas
- 🔢 NumPy
- 📊 Matplotlib
- 📓 Jupyter Notebook

---

## 📂 Dataset

The project uses a Stock Market dataset containing different information related to stocks.

The dataset includes features such as:

- 📈 Round Lot Size
- 🏢 Market Category
- 💰 Financial Status
- 📊 Other stock-related information

---

## 🔍 Data Analysis Performed

The following operations were performed during the analysis:

### 📋 Data Exploration
- Checking the dataset structure
- Viewing rows and columns
- Checking data types
- Finding missing values
- Generating statistical summaries

### 🔢 NumPy Operations
- Mean
- Maximum
- Minimum
- Standard Deviation
- Sum
- Variance
- 1D Array Operations
- 2D Array Operations

### 📊 Data Visualization
Different visualizations were created to better understand the dataset, including:

- 📊 Bar Charts
- 📈 Line Charts
- 📉 Histograms
- 🥧 Pie Charts

These visualizations help understand the distribution of **Market Categories, Financial Status, and Round Lot Size**.
